# Registrar

A very bloody simple registration helper. For Fabric Primarily, but also available on NeoForge and Forge if anyone needs it.

## Design Philosophy
I want to make a simple registration helper that can be used in any mod projects.
It should handle the abstraction layer quite well with a good documented usage and nuance of its usage.
The similar and much vast-er library is **tterag's Registrate**, I do like it very much, but it wasn't available for fabric
and I find it sometimes a bit nuanced to work with. But I guess that's mostly my issue, so I'd like to make a tool that hopefully
solves my own issue and other devs who's meeting the same nuances as me.
